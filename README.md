# Ecommerce Project

A machine learning and data analysis project for ecommerce customer analysis.

## Project Contents

- **Ecommerce project.ipynb** - Main Jupyter notebook with exploratory data analysis and models
- **ecproject.py** - Python module for ecommerce data processing
- **project1ml.py** - Machine learning models and utilities
- **Ecommerce Customers** - Customer data directory

## Setup

1. Install required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the Jupyter notebook:
   ```bash
   jupyter notebook "Ecommerce project.ipynb"
   ```

## Requirements

- Python 3.7+
- Jupyter Notebook
- pandas
- scikit-learn
- numpy
- matplotlib
- seaborn
